
# Atlas Student Records System 🎓

A Student Records Management System built using C#, ASP.NET Core, HTML, CSS, and JavaScript.

## Dashboard Preview

![Atlas Dashboard](screenshots/dashboard.png)

## Features

- Add student records
- Search students
- Update student information
- Delete student records
- Display student information
- Calculate average GPA
- Track student statistics

## Technologies

- C#
- .NET 10
- ASP.NET Core Web API
- Linked List Data Structure
- HTML5
- CSS3
- JavaScript

## Data Structure

The project uses a custom Singly Linked List implementation to manage student records.

## How to Run

Start the API:

```bash
dotnet run --project StudentRecordsApi --urls http://localhost:5050
```

Then open `StudentRecordsSystem/WebDemo/index.html` using Live Server.
